# Last Zone 2D

A top-down 2D battle royale game that runs fully offline in your browser. 30 players, 1 survivor. Built with plain JavaScript and the HTML5 Canvas API, in a single HTML file with no dependencies.

## Play

Open `index.html` in any modern browser. No install or internet connection needed.

## Features

- 5 weapons: pistol, SMG, assault rifle, shotgun, sniper rifle
- Loot: guns, ammo, bandages, medkits, armor vests
- 3600x3600 map with buildings, doors, trees, rocks and lakes
- Shrinking safe zone in 6 phases
- 29 AI bots (loot, fight, heal, flee the zone, react to gunshots)
- Easy / Normal / Hard difficulty
- Minimap, kill feed, damage indicators, procedural sound effects
- Keyboard + mouse and touch controls
- Wins, matches, kills and best rank saved in the browser

## Controls

| Key | Action |
| --- | --- |
| WASD | Move (Shift to sprint) |
| Mouse | Aim, hold left click to shoot |
| R | Reload |
| E | Pick up guns / armor (ammo and heals are automatic) |
| Q | Heal |
| 1 / 2 / Mouse wheel | Switch weapon |
| Esc | Pause |

Touch: left stick moves, right stick aims and fires, on-screen buttons for reload, pick up, heal and swap.
